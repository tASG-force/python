# Cheatsheet 

### Geradeaus 
```python
db.straight(distance=500)
```
distance: Distanz die der Roboter fahren soll in Millimetern 

### Drehen 
```python
db.turn(angle=90, absolute=False)
```
angle: Wert in grad auf/um sich der Roboter drehen soll<br>
absolute: Wenn True dreht sich der Roboter auf den Wert, wenn False um den Wert. Standardmäßig False, falls weggelassen.
